# Lab 01 — Linux File System and Permissions

## Objective
Practice Linux file and directory management
and understand file permissions.

## Commands
- pwd
- ls
- mkdir
- touch
- cp
- mv
- chmod
- chown

## Environment
- OS: Ubuntu
- Lab type: Local Linux environment

## Tasks
1. Create a project directory.
2. Create and organize files.
3. Inspect file permissions.
4. Change file permissions using chmod.
5. Verify the results.
